Changes: added descriptive column headers; retained all original measurement values and class labels.
The repository documents historical discrepancies with Fisher's original article. This project uses the downloadable iris.data variant without silently correcting its values.
150 observations, 50 per class; four measurements in centimetres. No personal data are present.
